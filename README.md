# 🤖 Projetos de Robótica Educacional com Arduino

Bem-vindo ao meu hub central de projetos! 
Este repositório foi criado com o objetivo de documentar minha jornada e estruturar um **material didático aberto** para o ensino de robótica, pensamento computacional e eletrônica para crianças e adolescentes.

## 🎯 Objetivo Pedagógico
Mais do que apenas código e circuitos, cada projeto aqui dentro é pensado como uma **situação de aprendizagem**. O foco é traduzir conceitos complexos de programação em projetos lúdicos, visuais e conectados com o mundo real dos alunos (como semáforos, postes que acendem sozinhos, etc.).

## 📚 Índice de Projetos / Planos de Aula

Abaixo estão os projetos estruturados, organizados do nível básico ao avançado. Clique em cada um para acessar o código-fonte (`.ino`) e a dinâmica de aula sugerida.

1. [🚦 Semáforo Interativo para Pedestres](./01-semaforo-interativo) - *Saídas digitais, estruturas condicionais e sinalização sonora.*
2. [🏙️ Poste Inteligente com LDR](./02-poste-inteligente) - *Sensores analógicos, calibração e leitura de luminosidade.*
3. [🚧 Cancela de Pedágio Automática](./03-cancela-pedagio) - *(Em breve) Introdução a Micro Servos e controle de ângulo.*
