# Semáforo Educacional 🚦🚦
Projeto simples de Arduino focado no ensino introdutório de robótica e eletrônica básica para crianças e jovens.

## 🎯 Objetivo Didático
Ensinar os conceitos básicos de saída digital (`digitalWrite`) e controle de tempo (`delay`), além de introduzir a montagem de circuitos em protoboard utilizando LEDs e resistores de forma visual e interativa.
